# Changelog

## v1.3.0-atoll - 2026-05-18

### Added

- Added a Liquid Glass panel material option with a brighter refractive opened-panel fill.
- Refined expanded session rows with glass card backgrounds, status rails, status orbs, and inset glass action panels.
- Added versioned release notes under `docs/releases/` so release bodies can be reviewed before publishing.

### Changed

- Expanded the update card to show the GitHub changelog inline from the latest release body.
- Refreshed the styled DMG background assets for the new local package.
- Updated `argmaxinc/argmax-oss-swift` resolution to `0.18.0` while keeping the manifest constrained below `1.0.0`.

### Compatibility

- No breaking app or packaging changes found during local verification.
- WhisperKit v1 remains excluded because its package structure still needs separate universal-build migration work.

## v1.2.0-atoll - 2026-05-18

### Added

- Added the Parakeet dictation engine and defaulted dictation to TDT v3.
