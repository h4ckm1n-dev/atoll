# Atoll v1.3.0-atoll - Liquid Glass Release

Highlights:
- Added a Liquid Glass panel material with a brighter refractive opened-panel fill.
- Polished session rows with glass cards, status rails, status orbs, and inset glass action panels.
- Added the expandable update changelog in Settings so users can inspect the latest GitHub release body from the app.
- Updated `argmaxinc/argmax-oss-swift` to `0.18.0` under the existing `<1.0.0` guard.
- Refreshed the styled DMG background for the local release package.

Breaking changes:
- None found. The Renovate dependency update resolves to `0.18.0`, not `1.x`, and the manifest still blocks WhisperKit v1 until the universal-build package-structure issue is handled separately.

Verification:
- `swift package update argmax-oss-swift`
- `swift build --product AtollApp`
- `zsh scripts/harness.sh ci`
- `zsh scripts/package-app.sh`

Install note:
This local build is unsigned unless a Developer ID identity is available in the local keychain. If macOS blocks first launch, right-click the app and choose Open, or run:

```bash
xattr -d com.apple.quarantine /Applications/Atoll.app
```

# Atoll v1.3.0-atoll - Liquid Glass 版本

重点:
- 新增 Liquid Glass 面板材质，打开后的面板有更明亮的折射流光。
- 优化会话行视觉，包括玻璃卡片、状态边栏、状态圆点和玻璃操作区。
- 在设置里的更新卡片中加入可展开的 GitHub 更新日志，用户可以直接查看最新 release 内容。
- 将 `argmaxinc/argmax-oss-swift` 更新到 `0.18.0`，同时继续用 `<1.0.0` 避开 WhisperKit v1 的包结构风险。
- 为本地发布包刷新了 DMG 背景。

破坏性变更:
- 未发现。Renovate 更新实际解析到 `0.18.0`，不是 `1.x`；manifest 仍然阻止 WhisperKit v1，直到单独处理 universal build 的包结构迁移。

验证:
- `swift package update argmax-oss-swift`
- `swift build --product AtollApp`
- `zsh scripts/harness.sh ci`
- `zsh scripts/package-app.sh`
